# Practical 2: Descriptive Statistics and Data Visualization using Python

## Aim
To perform descriptive statistical analysis and data visualization on the Student Rating dataset using Python.

## Libraries Used
- **Pandas:** For data manipulation and statistical analysis.
- **NumPy:** For numerical operations.
- **Matplotlib:** For creating graphs and visualizations.

## Dataset
The Student Rating dataset is obtained from GitHub. It contains information about 463 professors and 13 columns, including age, gender, beauty score, tenure, evaluation and number of students.

## Description

The following operations were performed:

1. Imported the required Python libraries.
2. Loaded the dataset from GitHub and converted it into a Pandas DataFrame.
3. Displayed the first five rows using `head()`.
4. Checked the number of rows and columns using `shape`.
5. Displayed all column names using `columns`.
6. Identified the dataset as cross-sectional data.
7. Calculated the mean, median, minimum and maximum of the students column.
8. Performed descriptive statistical analysis using `describe()`.
9. Created a histogram to display the distribution of beauty scores using 20 bins.
10. Grouped gender and beauty columns to calculate mean and standard deviation.
11. Rounded the statistical values to two decimal places.
12. Used cross-tabulation to compare tenure percentages between male and female professors.

## Important Results

- Total observations: **463**
- Total columns: **13**
- Mean number of students: **36.62**
- Median number of students: **23**
- Minimum number of students: **5**
- Maximum number of students: **380**
