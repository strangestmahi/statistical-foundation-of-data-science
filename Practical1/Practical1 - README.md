# Practical 1: Data Analysis and Visualization using Python

## Aim
To perform data analysis and visualization on the Student Rating dataset using Python libraries.

## Libraries Used
- **Pandas:** For data loading, manipulation and analysis.
- **Matplotlib:** For creating graphs and visualizations.
- **NumPy:** For numerical operations.

## Dataset
The Student Rating dataset is used to analyse professor information such as age, gender, minority status, tenure and evaluation scores.

## Description

The following operations were performed:

1. Imported the required Python libraries.
2. Loaded the Student Rating dataset using Pandas.
3. Displayed the first five rows of the dataset.
4. Calculated the percentage of visible minority professors who are tenured.
5. Used cross-tabulation to compare minority status and tenure.
6. Calculated the mean and standard deviation of professors' ages based on tenure.
7. Created a histogram to display the age distribution.
8. Created horizontal and vertical bar graphs to represent gender distribution.
9. Compared `pyplot.bar()` and `pyplot.barh()`.
10. Calculated the median evaluation score of tenured professors.

## Results

Some important results obtained:

- Percentage of visible minority professors who are tenured: **84.38%**
- Median evaluation score of tenured professors: **4.0**

Successfully performed data analysis and visualization on the Student Rating dataset using Python. Learned how to filter data, calculate statistical values, perform cross-tabulation and create different types of graphs.
